================================================================================
ROLES SUPORTADOS
================================================================================

1. super_admin
   - Acesso completo a todos os recursos
   - Pode fazer qualquer operação (read, create, update, delete, suspend)

2. tecnico
   - Acesso a recursos que possui (organizations via owner_technician_id)
   - Acesso a recursos explicitamente atribuídos (networks via technician_assignments)
   - Pode gerenciar dispositivos em redes que tem acesso
   - NÃO pode suspender recursos, apenas super_admin

3. freelancer
   - Acesso APENAS a tickets atribuídos a ele
   - Acesso a offers via dispatch system
   - NÃO pode acessar dispositivos, redes ou organizações diretamente

4. cliente_avulso (implícito)
   - Acesso via device_token (sem autenticação JWT)
   - Pode criar tickets standalone em dispositivos
   - Implementado via ClientOpenTicket + ensureStandaloneScope
